# Student Record and Academic Management Platform

## About the Project

The Student Record and Academic Management Platform is a centralized academic management solution designed to manage student records and academic information efficiently.

## Project Objective

To design a centralized platform for managing student records, courses, attendance, examinations, marks, results, and academic reports using Product Engineering, Design Thinking, Agile, and Scrum methodologies.
